# Expense Tracker

A simple expense tracker created using HTML, CSS and JavaScript.

## Features

- Add expenses
- Enter expense amount
- Select expense category
- Calculate total expense
- Delete expenses
- Simple and clean design

## Technologies Used

- HTML
- CSS
- JavaScript

## Categories

- Food
- Travel
- Shopping
- Other

## Project Files

- `index.html` - Website structure
- `style.css` - Website design
- `script.js` - Expense functionality
- `README.md` - Project information

## How It Works

Enter the expense name and amount, select a category, and click the Add Expense button.

The total expense is automatically calculated.
